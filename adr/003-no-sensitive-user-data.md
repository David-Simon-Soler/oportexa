# ADR 003: No almacenar datos sensibles

- Status: Accepted
- Context: En V0.1 no hay usuarios y las fases futuras deben reducir riesgo de privacidad.
- Decision: Aplicar minimización y no recoger datos sensibles que no sean imprescindibles.
- Consequences: Menor superficie de ataque y carga legal; las futuras funciones deberán diseñarse alrededor de perfiles mínimos.
