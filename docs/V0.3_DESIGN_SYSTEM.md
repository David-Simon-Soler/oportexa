# V0.3 Design System

Sistema visual inicial para Oportexa. Se ha implementado sin dependencias UI nuevas.

## Direction

Editorial data intelligence: precisión, claridad, confianza, inteligencia, transparencia, calma y profesionalidad.

## Color tokens

- `--background`: off-white cálido para el lienzo.
- `--surface`: blanco para superficies de lectura.
- `--foreground`: casi negro verdoso para máxima legibilidad.
- `--muted`: gris neutro para contexto.
- `--subtle`: gris suave para metadatos.
- `--border`: gris muy ligero.
- `--border-strong`: controles y separación visible.
- `--accent`: verde bosque para acciones y enlaces relevantes.
- `--accent-soft`: verde muy claro para filtros activos.
- `--open`: verde accesible para estados BDNS positivos.
- `--warning`: ámbar reservado para mensajes de advertencia.

El verde no rellena la interfaz: marca acción, foco, enlaces y estado abierto.

## Typography

Se conserva el stack local del sistema, sin Google Fonts ni dependencias externas. La jerarquía usa peso semibold, tamaños fluidos y tracking contenido. El hero utiliza `clamp` y no depende de mayúsculas decorativas.

## Spacing and layout

- Contenedor máximo aproximado: 78rem.
- Mobile: 1rem horizontal.
- Tablet: 1,5rem horizontal.
- Desktop: 2rem horizontal.
- Secciones con separación amplia y bordes horizontales ligeros.
- Contenido editorial limitado para mantener una lectura cómoda.

## Surfaces, borders and radius

Las superficies son blancas y escasas. Los paneles usan un radio moderado de 1rem; las cards de resultados son principalmente filas con separadores, no una colección de tarjetas flotantes. Las sombras se reservan para controles mínimos.

## Responsive

Validación estructural objetivo: 320, 390, 768, 1024 y 1440 px. El layout usa flex/grid responsive, cards verticales en móvil, toolbar adaptable y contenido centrado en desktop.

## States and accessibility

Los estados conservan copy neutral y factual. Se usan landmarks, labels, foco visible, enlace de salto al contenido, `aria-label`, `aria-current`, navegación por teclado y `prefers-reduced-motion`. Los textos sutiles deben mantener contraste WCAG AA; el foco no depende sólo del color.

## Principles

- Datos antes que decoración.
- Una acción primaria clara.
- Procedencia visible.
- No esconder incertidumbre.
- No usar color como único significado.
- No añadir animación gratuita, gradients, glassmorphism ni icon packs.
