# V0.3 Design Handoff — implemented direction

La dirección visual V0.3 está implementada en `apps/web`. Este documento deja constancia de la relación entre decisiones visuales y arquitectura funcional. No añade producto nuevo.

## Dirección aplicada

`EDITORIAL DATA INTELLIGENCE`: una interfaz sobria, clara y orientada a descubrir datos públicos. La composición prioriza tipografía, ritmo, espacio y relaciones de datos frente a efectos decorativos.

## Implementado

- Header responsive con navegación de convocatorias, regiones, sectores, organismos y beneficiarios.
- Homepage editorial con hero, buscador protagonista, accesos, oportunidades abiertas, exploración taxonómica, estadísticas contextualizadas y fuente/trust.
- Catálogo con buscador, toolbar de filtros, filtros activos, ordenación, lista, estados vacíos y paginación.
- Cards de densidad media con estado BDNS, título, organismo, presupuesto, fechas y relaciones resumidas.
- Ficha con breadcrumbs, hero de convocatoria, resumen, contenido editorial, fuente oficial y provenance.
- Índices y detalles taxonómicos con el mismo lenguaje visual.
- Footer factual sin enlaces inventados.
- Tokens visuales en `globals.css`.

## Jerarquía que debe conservarse

En cards: estado y título primero; organismo y presupuesto después; relaciones, fechas y BDNS como contexto.

En ficha: título/estado, resumen, presupuesto, relaciones, finalidad/descripción, bases, fondos, provenance y fuente oficial.

## Estados que debe conservar la UI

No resultados, error de catálogo, 404, dataset parcial, presupuesto desconocido, fecha no indicada, relación vacía y URL oficial ausente. Los NULL nunca se convierten en cero, false o cerrado.

## Límites no modificables

- CORE-only desde web.
- Server Components y DAL server-only.
- Semántica literal de `is_open`.
- Fuente BDNS claramente visible.
- No afirmar cobertura nacional completa.
- Sin auth, pagos, IA, alertas, ads, afiliación ni API pública.
- Sin combinaciones SEO arbitrarias.

## Pendiente de una revisión visual posterior

La siguiente revisión puede ajustar detalles de composición y responsive, pero no debe reabrir contratos de datos, rutas, semántica de estados, seguridad ni SEO.
