# V0.3 accessibility contract

Contrato estructural para el diseño e implementación posterior. No fija colores, tipografía ni estilo visual.

- Un H1 por página.
- `header`, `nav`, `main` y `footer` semánticos.
- Labels reales asociados a inputs.
- Navegación completa por teclado.
- Foco visible.
- Links distinguibles sin depender sólo del color.
- Botones con nombre accesible.
- Estados de error anunciables cuando proceda.
- Skip link si el diseño final lo necesita.
- Targets táctiles razonables.
- Contraste mínimo WCAG AA en la implementación visual.
- No usar color como único indicador de `is_open` o errores.
- Breadcrumbs implementados como navegación semántica.

La web sigue siendo server-rendered. No se añadirán estados cliente innecesarios para resolver accesibilidad.
