# V0.3 Product Discovery

Este documento es un handoff de producto. No implementa funcionalidades V0.3.

## Objetivo

Convertir el dataset CORE en una experiencia útil para encontrar, entender y explorar oportunidades públicas en España.

## Alcance candidato

### MUST

- Search server-side sobre convocatorias.
- Filtros por estado, región, sector y beneficiario.
- Resultados paginados y rápidos.
- Ficha individual con título, organismo, fechas, presupuesto y fuente oficial.
- Navegación por regiones y sectores con inventario real.
- Transparencia de fuente y freshness.
- Estados claros para ausencia de resultados, datos incompletos y errores.

### SHOULD

- Páginas de organizaciones.
- Páginas de beneficiarios.
- Vista de oportunidades abiertas.
- Señalización de convocatorias sin fecha final.
- Convocatorias relacionadas mediante relaciones de datos explicables.
- Enlazado interno SEO-first con contenido diferencial.

### LATER

- Closing soon cuando exista suficiente cobertura con fechas finales fiables.
- Comparativas históricas y estadísticas.
- Personalización y alertas, después de validar el producto público.

## Principios

- SEO-first, sin URLs programáticas arbitrarias.
- Contenido server-rendered útil.
- Rápido, accesible y mobile-first.
- Sin thin pages.
- Transparencia de fuente y procedencia.
- Freshness visible cuando sea relevante.
- Datos derivados claramente diferenciados de datos oficiales.
- Mínima recopilación de datos de usuario.

## Fuera de V0.3 inicial

No incluye auth, usuarios, perfiles, favoritos, alertas, IA, LLM, embeddings, matching, pagos, publicidad, afiliación, leads ni API pública.

## Gates antes de construir

- Definir queries y contratos DAL sobre CORE.
- Mantener PostgreSQL server-only y SQL parametrizado.
- No publicar páginas cuya cobertura o freshness no esté demostrada.
- Medir search y filtros sobre el dataset ampliado antes de optimizar.
- Mantener visible el estado `LOCAL PARTIAL DATASET` hasta alcanzar el launch data gate.
