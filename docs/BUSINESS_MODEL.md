# Modelo de negocio futuro

El producto gratuito será el motor de distribución y confianza. La monetización se introducirá solo cuando exista tráfico y utilidad suficientes:

- publicidad display discreta y claramente separada del contenido;
- afiliación contextual, con identificación de la relación;
- generación de leads claramente identificada y consentida;
- plan Pro para automatización, personalización y capacidades avanzadas;
- plan Business para equipos, operación y necesidades profesionales;
- API futura para acceso programático y casos de integración.

No se fijan precios definitivos: deberán validarse mediante investigación, uso y experimentación posterior.
